# File Organizer

A simple Python project that organizes files into different folders based on their file extensions.

## Features

- Organizes files into categories such as audio, video, images, documents and ZIP files.
- Searches for files inside subfolders.
- Preserves the original folder structure.
- Creates a backup before organizing files.
- Deletes empty folders after moving files.
- Displays the number of files in each category.
